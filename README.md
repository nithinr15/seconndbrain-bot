
🤖 Telegram Reminder Bot (Supabase + Railway + Python)

A smart personal reminder bot built using Python, Supabase, and Telegram — hosted 24×7 for free on Railway ☁️.
It remembers what you tell it, stores reminders in the cloud, and notifies you right on Telegram.

⸻

✨ Features

✅ One-time reminders — remind me to call mom at 7pm
✅ Recurring reminders — remind me every day at 8am to meditate
✅ Smart summaries — /list today, /list week
✅ Delete reminders — /delete <id>
✅ Persistent storage via Supabase
✅ Timezone-aware (auto-adjusted to IST 🇮🇳)
✅ Free hosting on Railway

⸻

⚙️ How It Works

Telegram User ↔ Bot (Python on Railway) ↔ Supabase Database

	•	You message the bot.
	•	It parses your reminder, stores it in Supabase.
	•	A background worker checks due reminders every 30s and sends you notifications.

🧰 Setup Instructions

1️⃣ Prerequisites
	•	Python 3.9 or later
	•	Telegram Bot Token (get one from @BotFather)
	•	Free Supabase account → https://supabase.com
	•	Free Railway account → https://railway.app

⸻

2️⃣ Supabase Setup
	1.	Create a new Supabase project
	2.	Go to SQL Editor and run:

create table if not exists reminders (
  id bigint generated by default as identity primary key,
  chat_id bigint,
  task text,
  remind_time timestamptz,
  recurring boolean default false,
  frequency text,
  created_at timestamptz default now()
);

	3.	Go to Project Settings → API
Copy your:
	•	Project URL
	•	anon public key

⸻

3️⃣ Local Setup

Clone the repo:

git clone https://github.com/YOUR_USERNAME/telegram-reminder-bot.git
cd telegram-reminder-bot

Install dependencies:

pip install -r requirements.txt

Create a .env file (or copy .env.example):

cp .env.example .env

Fill in your details:

BOT_TOKEN=your_telegram_bot_token
SUPABASE_URL=https://yourprojectid.supabase.co
SUPABASE_KEY=your_anon_public_key

Run the bot locally:

python reminder_bot.py

You’ll see:

🤖 Bot running with recurring reminders, smart summaries, and IST timezone...

Then open your bot on Telegram and try:

/start
remind me to drink water in 1 minute
/list


⸻

4️⃣ Deploy to Railway ☁️
	1.	Push this repo to GitHub:

git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/telegram-reminder-bot.git
git push -u origin main


	2.	Go to Railway → New Project → Deploy from GitHub
	3.	Add Environment Variables:

BOT_TOKEN = your_telegram_bot_token
SUPABASE_URL = https://yourprojectid.supabase.co
SUPABASE_KEY = your_anon_public_key


	4.	Set Start Command:

python reminder_bot.py


	5.	Click Deploy

✅ Done — your bot is now live 24×7!

🧪 Example Commands

Command	Description

remind me to call mom at 7pm	One-time reminder

⸻

🕓 Timezone Handling
	•	All reminder times are stored in UTC in Supabase
	•	All user interactions (input & output) are converted to IST (Asia/Kolkata)

So remind me at 8am → fires at exactly 8:00 AM IST 🕗
